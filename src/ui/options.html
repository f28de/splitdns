常规

总开关关闭后，动态规则、内置规则集、分流代理与 DoH 查询全部停止：浏览器恢复默认网络行为， 扩展也不会再向任何上游发送域名。你的规则与代理配置会保留，重新开启后自动恢复。

上游 DNS

全部通过 DoH（HTTPS）查询，不使用系统 DNS，因此不受本地 DNS 劫持影响。 上游地址必须是 https；明文 http 仅允许本机回环地址（如 127.0.0.1），用于本地调试。

按域名分流到不同上游

等价于 mosdns 的 sequence + upstream 选择：自上而下匹配，命中第一条即生效。

自定义上游

URL 必须是 https（本机回环可用 http），需支持 RFC 8484 JSON 形式（返回 application/dns-json），用 {name} 与 {type} 占位。

分流代理

用 PAC 脚本按域名决定"走代理 / 直连"，对应 mosdns 的分流能力。 此功能需要 proxy 权限，仅在开启时申请；关闭后会立即恢复系统代理设置。

启用分流代理
开启时浏览器会提示授予"控制代理设置"权限

说明

  • PAC 脚本只支持 domain / full / keyword 三种规则，正则规则会被忽略（浏览器 PAC 引擎不支持可靠的正则）。
  • 本地地址（localhost、10.x、192.168.x、172.16-31.x、*.local）始终直连。
  • 直连列表与 @@ 例外始终优先于代理列表。
  • 不支持代理认证（用户名/密码）；需要认证时请在本机代理客户端上放行 127.0.0.1。

规则订阅

从远程地址拉取规则文本，与手动规则合并编译。拉取时只会申请该订阅域名自身的访问权限。

支持 hosts、Adblock 域名语法与 mosdns 前缀语法；通配类规则会被自动跳过。

导入导出

配置以 JSON 保存，不含任何浏览记录。可用于多设备同步或备份。

重置

清除全部规则与设置，恢复初始状态。此操作不可撤销。

能力边界

浏览器扩展无法接管操作系统 DNS。本扩展实现的是"策略层"：域名匹配、拦截/白名单、 按域名分流上游与代理、DoH 缓存与观测。真正的系统级 DNS 接管仍需 mosdns 等本地方案。
